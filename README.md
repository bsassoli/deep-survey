## Installation

To install Deep Survey, follow these steps:

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/deep-survey.git
    ```
2. Navigate to the project directory:
    ```bash
    cd deep-survey
    ```
3. Install the dependencies:
    ```bash
    npm install
    ```

## Usage

To start using Deep Survey, run the following command:

```bash
npm run dev
```

This will launch the application, and you can access it via your web browser at `http://localhost:3000`.
